# DBP-HUB 更新日志

## v0.9.5 — Markdown 插件支持
> 发布日期：2026-08-14

### ✨ 新增
- **Markdown 插件类型**：`.md` / `.markdown` 文件可直接作为插件加载
- **内置零依赖解析器**：支持标题、加粗、斜体、删除线、行内代码、代码块、链接、图片、列表、引用、水平线、表格、任务列表
- **暗色主题渲染**：自动套用框架 CSS 变量，视觉统一
- **复制源码按钮**：一键复制原始 Markdown 内容
- **查看源码按钮**：展开/折叠原始 Markdown 文本

### 🔧 优化
- 插件类型自动检测（`pluginType` 字段或文件扩展名）
- 懒加载架构统一处理 JS / HTML / Markdown 三种格式
- 错误面板显示插件类型和详细错误信息

### 🐛 修复
- 修复折叠菜单点击两次才生效的问题
- 修复滑块 thumb 和 fill 不同步的问题
- 修复移动端遮罩覆盖菜单的问题

## v0.9.4 — HTML 插件系统
> 发布日期：2026-08-13

### ✨ 新增
- **HTML 插件类型**：纯 HTML 文件可直接作为插件
- **iframe 模式**：完全隔离渲染，适合独立工具
- **inline 模式**：直接插入 DOM，继承框架样式
- **sandbox 安全隔离**：iframe 带安全属性

### 🔧 优化
- 按钮样式平滑过渡（cubic-bezier 缓动）
- 路由切换自动回到顶部
- 加载指示器

---

## v0.9.3 — 插件懒加载
> 发布日期：2026-08-12

### ✨ 新增
- **按需加载**：点击菜单时才 fetch 插件 JS
- **并发去重**：同时多次点击只发一次请求
- **缓存复用**：已加载插件不重复请求

### 🔧 优化
- 首屏加载量从 ~20 个文件降到 1 个 JSON
- 进度条显示真实加载步骤
