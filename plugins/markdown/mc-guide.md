> 适用于 Java 版 1.21+ · 由 DBP-HUB 整理

## 🌍 第一天：活下去

### 收集资源
- **木头** × 10：用手撸橡树/白桦的树干
- **圆石** × 20：用木镐挖石头
- **煤炭** × 5：用木镐挖煤矿石（黑色带灰点）
- **羊毛** × 3：杀羊或找羊剪毛

### 制作优先级
1. 木镐 → 石镐（挖石头更快）
2. 石镐 → 石斧（砍树更快）
3. 熔炉（圆石 × 8）→ 烧木炭（木头当燃料）
4. 火把（煤炭 + 木棍）→ 照亮周围防怪

### 建造避难所
> 天黑前必须找到或建好封闭空间

- 在地面挖 3×3×2 的洞 → 封顶 → 放火把
- 或用圆石垒 5×5 的墙 + 门
- **绝对不要**在树下/草丛旁过夜

## ⛏️ 挖矿策略（1.21 版）

### 各矿物最佳高度
- **煤炭**：Y = 95（露天到处都是）
- **铜**：Y = 48
- **铁**：Y = 16（含水层多，注意淹水）
- **金**：Y = -16
- **红石**：Y = -59
- **钻石**：Y = -59（含水层，带桶装水）
- **青金石**：Y = 0
- **绿宝石**：只在山地生物群系（Y = 236）

### 挖矿技巧
- **鱼骨式矿道**：主道 2 格高 × 3 格宽，每 3 格向两侧挖分支
- **听声辨怪**：挖掘时听到嘶嘶声 → 苦力怕靠近 → 立刻后退
- **随身带水**：遇到熔岩可以浇灭
- **标记回路**：沿途放火把，确保能找到回去的路
