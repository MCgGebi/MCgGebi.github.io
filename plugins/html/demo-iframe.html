直接显示无框，铺满整块区域

规范要点：
① 本文件不需要写标题和导航栏 —— 标题「HTML · iframe（无框全屏）」已写在顶栏，由 plugins.json 的 title 字段驱动。
② 若要调用框架能力，可用 window.parent.copyText() / window.parent.showToast()。
③ CSS 变量（--bg / --panel / --accent 等）会随亮色/暗色主题自动变化，建议直接引用。
